## API Reference
- [Create a Payment Request.](https://developer.azupay.com.au/reference/createpayidpaymentrequest.md): Creates a payment request. Once created, your customer can make a payment to the specified PayID. You can poll for PaymentStatus using getPaymentRequest to determine whether or not the required payment was made by the customer.
- [Delete a Payment Request.](https://developer.azupay.com.au/reference/deletepaymentrequest.md): Delete an existing payment request, de-registering the associated PayID in the process.
- [Search for Payment Requests.](https://developer.azupay.com.au/reference/searchpaymentrequest.md): Search for Payment Requests
- [Get a Payment Request.](https://developer.azupay.com.au/reference/getpaymentrequest.md): Retrieves an existing PayID PaymentRequest.  Use the contents of the response body to determine whether the customer has made their payment.
- [Refund a PaymentRequest.](https://developer.azupay.com.au/reference/refundpaymentrequest.md): Refund a previously settled PaymentRequest back to the customer's source of funding. Optionally supply the amount to refund. Refunds requests can be rejected for the following failure reasons:  | `failureCode`    | `failureReason`                                                                 | |------------------|---------------------------------------------------------------------------------| | ERR0.03          | Refunds can only be done on COMPLETE, RETURN_COMPLETE or RETURN_FAILED payments | | ERR0.05          | Missing id.                                                                     | | ERR0.06          | Refund amount value must be a number                                            | | ERR0.07          | Refunds cannot be done against PaymentRequest\'s with multiPayment set to true  | | ERR0.08          | Refunds can only be done on COMPLETE, RETURN_COMPLETE or RETURN_FAILED payments | | ERR0.09          | Refund for this client can only be for the full amount                          | | ERR0.10          | Refund amount must be less than or equal to original payment amount             | | ERR0.11          | Insufficient funds to process this refund                                       |
- [Make a Payment.](https://developer.azupay.com.au/reference/makepayment.md): Make an outbound payment to the provided PayID or BSB/Account Number. Once made, you can poll for PaymentStatus using getPayment to determine whether or not the payment was settled to the payee.
- [Search for Payments.](https://developer.azupay.com.au/reference/searchpayment.md): Search for Payments
- [Get a Payment.](https://developer.azupay.com.au/reference/getpayment.md): Retrieves the status of a previous Make a Payment call. Use the contents of the response body to determine whether the payment has completed.
- [Create a Payment Agreement](https://developer.azupay.com.au/reference/createpaymentagreement.md): Create a Payment Agreement
- [Search for Payment Agreements.](https://developer.azupay.com.au/reference/searchpaymentagreement.md): Search for Payment Agreements
- [Amend a Payment Agreement](https://developer.azupay.com.au/reference/createpaymentagreementamendment.md): Amend a Payment Agreement
- [Change Status of a Payment Agreement](https://developer.azupay.com.au/reference/changestatusofpaymentagreement.md): Change the status of a Payment Agreement
- [Create or amend a Payment Scheduler](https://developer.azupay.com.au/reference/createorupdatepaymentscheduler.md): Creates a scheduler against an active payment agreement, or amends the existing one. Upsert keyed on paymentAgreementId. Amendments require the current version.
- [Retrieve a Payment Scheduler](https://developer.azupay.com.au/reference/getpaymentscheduler.md): Returns the scheduler for the given payment agreement, with its current state.
- [Create a Payment Agreement Request](https://developer.azupay.com.au/reference/createpaymentagreementrequest.md): Create a Payment Agreement Request
- [Initiate a Payment](https://developer.azupay.com.au/reference/makepaymentinitiation.md): Initiate a Payment
- [Refund for Payment Initiation](https://developer.azupay.com.au/reference/refundpaymentinitation.md): Refund for Payment Initiation (PayTo Transactions)
- [Search for Payment Initiation](https://developer.azupay.com.au/reference/searchpaymentinitiation.md): Search for Payment Initiation (PayTo Transactions)
- [Get a Payment Initiation](https://developer.azupay.com.au/reference/getpaymentinitiation.md): Retrieves an existing Payment Initiation (PayTo Transaction).
- [Check account BSB for NPP and PayTo reachability.](https://developer.azupay.com.au/reference/enquireaccount.md): Check if NPP or AzupayTo payments can be sent to the account issuer identified by the given BSB.
- [Confirm the BSB/account number and name of a payee.](https://developer.azupay.com.au/reference/checkaccountdetails.md): The purpose of this operation is to validate the BSB/account number and name via Confirmation of Payee (CoP).
- [Check the status of the PayID.](https://developer.azupay.com.au/reference/checkpayid.md): Check if the PayID is registered and able to accept NPP and PayTo payments.  Also support validation of bsb and account number attached to the PayID.
- [Get Reports](https://developer.azupay.com.au/reference/getreport.md): Provides a list of reports that can be passed onto GET /report/download API endpoint. You can supply  `month + timezone` query parameters OR you can supply `fromDate + toDate`. The former provides you a list of all  reports automatically generated by azupay whilst the latter provides you with a report for the date range  specified.  Because `fromDate` and `toDate` contain special HTML entities (i.e. `:` and `+`), they must be encoded. Example: `2022-06-02T12:11:00.999+0530` must be supplied as `2022-06-02T12%3A11%3A00.999%2B0530`
- [Get Report download Url](https://developer.azupay.com.au/reference/downloadreport.md): Gets a time limited link to download the specified report
- [Get current balance](https://developer.azupay.com.au/reference/getbalance.md): Returns balance of your Azupay account.
- [Create or replace a client](https://developer.azupay.com.au/reference/createclient.md): Create new sub-clients. Sub-clients are children of your own client (master-client).  Duplicates can be prevented by using the same value in `clientTransactionId` in the request. It would also replace an existing client if the same `clientTransactionId` is provided in the request.  This API is only available to some Azupay customers. Please contact us for more information.
- [Disable a sub-client](https://developer.azupay.com.au/reference/deleteclient.md): Disable a sub-client. Sub-client is a child of your own client (master-client).  This API is only available to some Azupay customers. Please contact us for more information.
- [/clients/{clientId}/lowBalanceAlert/threshold](https://developer.azupay.com.au/reference/getclientlowbalancealertthreshold.md)
- [Set low balance threshold to trigger alerts](https://developer.azupay.com.au/reference/updateclientlowbalancealertthreshold.md): Set low balance threshold to trigger alerts when the balance goes lower than the specified limit. When this happens, an email is sent to the specified recipients.
- [/clients/{clientId}/lowBalanceAlert/emailAddresses](https://developer.azupay.com.au/reference/getclientlowbalancealertemailaddresses.md)
- [Set email addresses to send the low balance alerts](https://developer.azupay.com.au/reference/updateclientlowbalancealertemailaddresses.md): Set the email addresses to send the alerts when the balance goes lower than the specified limit.
- [Create API keys for Sub Merchants](https://developer.azupay.com.au/reference/apikeysprovision.md): Create API keys
- [Get API keys for Sub Merchants](https://developer.azupay.com.au/reference/getapikeys.md): Get API keys
- [Update API keys for Sub Merchants](https://developer.azupay.com.au/reference/updateapikeys.md): Update API keys
- [Gets an API key based on the API key ID.](https://developer.azupay.com.au/reference/getapikey.md): Get API key
- [Enable OAuth2 for a client](https://developer.azupay.com.au/reference/enableclientoauth2.md): Enable OAuth2 for a client
- [Get OAuth2 configuration for a client](https://developer.azupay.com.au/reference/getclientoauth2.md): Get OAuth2 configuration for a client
